# Healthcare Analytics for Doctor Visits

## Project Overview
This project analyzes healthcare data to understand doctor visit patterns and explore relationships among health conditions, illness burden, and healthcare utilization.

## Objectives
- Analyze doctor visit patterns using exploratory data analysis.
- Study the relationship between self-reported health and doctor visits.
- Apply statistical analysis and regression modeling.
- Use K-Means clustering to identify patient groups with different healthcare needs.

## Technologies Used
- Python
- Jupyter Notebook
- Pandas and NumPy
- Matplotlib and Seaborn
- SciPy and Statsmodels
- Scikit-learn

## Project Files
- `healthcare_analysis.ipynb` — Notebook containing the analysis, visualizations, and models.
- `doctor_visits.csv` — Dataset used for analysis.
- `requirements.txt` — Required Python libraries.

## How to Run
1. Download or clone this repository.
2. Install the required libraries using `pip install -r requirements.txt`.
3. Open the notebook in Jupyter Notebook or Google Colab.
4. Run the notebook cells in order.

## Results
The analysis explores doctor visit frequency, associations between health indicators and healthcare utilization, regression results, and patient clusters.
